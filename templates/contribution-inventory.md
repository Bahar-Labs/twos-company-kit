# Contribution Inventory

Fill this out independently, then compare with your collaborator. The gaps between your versions are the conversations you need to have. See [01 The Handshake](../01-the-handshake.md) for how to run the comparison.

---

## Section 01. Collaborator: _______________

| Field | Your answer |
|---|---|
| **Name or handle** | |
| **Entity (if any)** | |
| **What I'm bringing that already exists** | (code, content, designs, a domain, an audience, a methodology, existing work) |
| **What I'm committing to build** | (be specific: "the frontend" is too vague; "a React dashboard with auth and 3 views" is right) |
| **Skills I bring** | (not resume lines -- actual things you can do that the other collaborator can't) |
| **Time I can commit** | (hours per week, and for how long -- "until it ships" is not a timeline) |
| **Distribution I bring** | (audience, community, email list, social following, co-marketing relationships) |
| **What I need from the other collaborator** | (the thing that made you want to collaborate instead of build alone) |
| **What I'm NOT willing to do** | (just as important -- hosting? customer support? marketing? sales calls?) |
